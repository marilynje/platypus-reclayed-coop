Platypus Reclayed — Online Co-op (неофициальный мод)
=====================================================

Онлайн-кооператив на двоих через Steam: пригласили друга — летите вместе.
У обоих должна быть одна версия игры (Steam, Windows) и этот мод.

УСТАНОВКА
1. Закройте игру.
2. Распакуйте архив в любую папку.
3. Дважды щёлкните install.bat.
   Скрипт сам найдёт игру в Steam, скачает BepInEx 5 (загрузчик модов) с GitHub
   и положит мод. Файлы игры не меняются.
   Если игра не нашлась: в PowerShell из этой папки
     .\install.ps1 -Game "путь к папке Platypus Reclayed"
   (Steam → Свойства → Установленные файлы → Обзор).
4. Запустите игру ИЗ STEAM (иначе не откроется окно приглашения Steam).
5. Один раз: Моды → Дополнения → включите «Online Co-op».

КАК ИГРАТЬ
Хост:
  Главное меню → «Совместная игра» → сложность → мир → выбор корабля.
  Справа внизу — «Пригласить друга»: откроется окно Steam, выберите друга.
Друг:
  Принимает приглашение в Steam — его игра сама откроет выбор корабля.
Оба:
  Каждый выбирает свой корабль (хост — слева, друг — справа) и жмёт «Готов».
  Передумали — «Отмена». Игра начинается, когда готовы оба.
  «Выйти» — выход из совместной игры у обоих.
  Пауза (Esc) общая. Обрыв связи — игра ждёт переподключения до 60 секунд.

ЕСЛИ НЕ РАБОТАЕТ
- «Пригласить друга» ничего не открывает — включите оверлей Steam
  (Steam → Настройки → В игре) и запускайте игру из Steam.
- Нет пункта «Совместная игра» — включите «Online Co-op» в Моды → Дополнения.
- «Different game builds» — у вас разные версии игры, обновите обе.
- «Mod version mismatch» — поставьте одинаковую версию мода.
- Лог: BepInEx\LogOutput.log в папке игры.

УДАЛЕНИЕ
uninstall.bat — убрать мод. Совсем вернуть игру как было:
  .\uninstall.ps1 -RemoveBepInEx

Неофициальный фанатский мод, не связан с Claymatic Games.
